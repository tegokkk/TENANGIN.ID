# TENANGIN.ID Frontend

Aplikasi SPA React + Vite (JavaScript ESM) dengan CSS Modules dan CSS custom properties tanpa CDN eksternal.

## Perintah Penting

- `npm run dev` — Menjalankan server Vite pada port `5173` dengan proxy `/api` ke `http://127.0.0.1:3000`.
- `npm run build` — Menghasilkan build produksi ke `dist/`.
- `npm test` — Menjalankan uji komponen Vitest + React Testing Library.
- `npm run test:e2e` — Menjalankan uji browser end-to-end Playwright.
- `npm run lint` — Menjalankan ESLint frontend.
